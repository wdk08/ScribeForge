# ScribeForge v1.0.1

- Indent selected paragraphs with Tab and Shift+Tab. The editor reflows text across visible pages as you edit.
- Choose Letter, A4, A5, or custom dimensions, with portrait or landscape orientation and adjustable margins.
- Apply a project style to detected chapter headings, override individual headings, or create reusable styles from formatted text.
- Design a front cover, a front and back cover, or a full wrap with a calculated or manual spine. Save the editable cover with the manuscript and export it separately as PNG or PDF.

Existing ScribeForge manuscripts remain compatible. Use the desktop downloads to install this update.
