ScribeForge is Forge Studios’ local writing app for novels, short stories, poetry, and other prose.

- Write one continuous rich-text manuscript with mixed fonts and formatting, customizable paragraph styles, page layout, and find and replace.
- Navigate chapters and see their word counts with the read-only Chapter Navigator. Custom styles can mark chapter headings.
- Keep manuscripts in a local library with autosave, a recovery checkpoint, and portable `.stf` exports that preserve formatting and applied styles.
- Track writing activity and sessions. Read to Me uses an installed local voice. The Profanity Analyzer provides editable groups, phrase matching, and chapter filters.
- Import STF, DOCX, and UTF-8 TXT. Export STF, DOCX, EPUB, and TXT, or save a PDF from the print panel.

Use the [browser edition](https://wdk08.github.io/ScribeForge/) or download the installer for Apple Silicon macOS, Intel macOS, or Windows x64 below. Browser and desktop libraries are stored separately. Use `.stf` exports to move manuscripts between them.

ScribeForge v1.0.0 uses manual updates through the [releases page](https://github.com/wdk08/ScribeForge/releases/latest).
